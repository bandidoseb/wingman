**Voice-AI onboarding discovery call** (Sebastian 2026-07-11) — the sharpened version of the moat's "AI
voice-call later" capture (Phase 1d). Instead of a static form, a voice AI runs a REAL discovery on every user:
1. Walks the Sales DNA questions and **keeps chunking down on each answer while it senses more context to get**
   ("cash flow to do what?" → "what would that free you up for?" …).
2. **Moves to the next question** once it judges it has enough.
3. When done, **tells the rep what to do next** and **auto-fills the entire Sales DNA page itself** from the call.
4. Rep opens the page, **sees it filled in, edits** anything.

**Why:** most reps won't chunk down on themselves (Sebastian did only because he knows the value) — so a passive
form captures shallow DNA and the live cards stay generic. The interview pulls the full belief map out of them
with zero effort → richer DNA → sharper cards. Bonus: a **data goldmine** on offers/objections/how top closers
talk that no competitor has. Point Wingman's own digging skill at the REP.

Also locked same session: the problems-vs-goals capture question becomes FOUR options —
`Problems first · Goals first · I read the room · I'm not sure` (adaptive ≠ don't-know; only "not sure" triggers
the Syntax auto-detect fast-follow). Needs a `SalesSyntax` 4th value + UI.
