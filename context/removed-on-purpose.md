`npm run context:verify` proves it by checking every line against the frozen snapshot.

**How to read this:** each entry names the file, quotes the exact line that no longer exists,
and says why. If you disagree with any of these, everything is recoverable:


**How this file works mechanically:** `context-verify` treats a line as legitimately gone only
if it appears here after `REMOVED:`. Anything missing and *not* listed here fails the check.
So this file can't quietly fall out of date — if I removed something and forgot to record it,
the verifier fails until it's written down.
