## What Broke

- **Phase 1 reviewer caught a real blocker before merge (fixed).** First version of `validateStages` used `status: "incomplete"`, which violates the `call_stages` CHECK constraint (`complete|partial|skipped|early|lost`) — and because the supabase insert error wasn't checked, it would have failed **silently**, leaving the stage heatmap permanently blank while logging "saved." Fixed: switched to `"skipped"` (valid + renders grey "—"), updated the AI prompt to match, added explicit insert-error logging. Verified the constraint + the FlightLog renderer directly before re-merging.
- **Nothing regressed in production.** Phase 0 + Phase 1 both verified live. Transcript pipeline intact end-to-end.
- **Disposition HUD bug re-observed** (2nd call of a session — buttons unresponsive, card auto-dismissed). Pre-existing, not Phase-related (Known Issue #35).

## Decisions Made and Why

| Decision | Reason |
|----------|--------|
| Phase 1 also silences keyword/KB autonomous cards (not just the poll) | Acceptance is "ambient dot only, no pop-ups"; scout was cut so there's no later keyword-demotion step. Clean silent state now; Phase 3 adds summon. |
| Stage derivation = idempotent delete-then-insert + checked insert error | Post-call is fire-and-forget and can re-run; supabase-js doesn't throw on DB errors, so silent-failure must be guarded. |
| Deferred the double-end race fix (handleAutoEnd lacks isEndingRef guard) | Pre-existing, rare, and touches the auto-stop chain (Invariant 5) — spun off as its own task rather than bolt onto Phase 1. |
| Scout CUT from v1 (timer-driven summary) | Scout was a responsiveness optimization, not load-bearing; timer + live buffer cover it. Removed build + mental complexity. |
| Call framework: show 4 universal stages, coach the depth underneath | Avoids "this isn't how I sell" friction without dumping the elite standard. Concepts are universal; jargon labels + rigid sequence are what feel imposed. |
| Sales DNA personalizes CONTENT, never the framework standard | If DNA learned a rep's flow, it could codify a bad process (student grading their own exam). Content adapts; the bar holds. |
| Post-call viz = gradient-colored labeled blocks; scatter only for a multi-call trend | Blocks beat scatter for ~6 labeled categories; scatter needs 2 real axes to mean anything. |
