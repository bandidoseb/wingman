## What Got Built Today

- **Summarizer "Cole-brain" redesign — the big one.** Reworked the live Belief Ladder summarizer (`src/lib/wingman/belief-ladder.ts` — `calls.live_summary`, the chokepoint EVERY live card reads) from a 2-layer scorecard into the 5 layers an elite closer actually holds in their head. Driven top-down from "if Cole Gordon / Jeremy Miner built this, what would their brain capture?" Changes:
  - **⚠️ relabel "at-risk" → "objected"** — an unlocked ⬜/🟡 belief is ALSO latent risk (a loaded objection that fires at the close); ⚠️ now means the objection already FIRED (handle now). Glyphs unchanged, so `close-readiness.mjs` (parses glyphs, not the word) is unaffected.
  - **Emotional-ownership ✅ bar** on Pain/Cost/Desire — a flat logical concession ("yeah I should fix that") is 🟡; ✅ requires real heat/stakes in their own words. People buy the beliefs they FEEL.
  - **Money (belief 5) = RESOURCES** — records capacity/means from discovery ("has ~$8k saved, spouse co-decides"), not just the price flinch.
  - **KEY ANCHORS** (evolves "THEIR EXACT WORDS") — per-belief verbatim ammunition (`• [Belief] "quote"`), ≤8, update-in-place, later-sharper supersedes vaguer. This is the [[Prospect Anchor Capture]] feature landing in the summarizer. Sales-DNA-specialized: the offer tells the summarizer what SHAPE anchors take (number vs feeling vs status) without ever supplying the words.
  - **COMMITMENTS ledger** (new, ≤3) — micro-yeses + conditional yeses with the condition named (`"if it gets me clients, cost isn't an issue" (conditional yes — condition: proof)`). Cole's close is assembled from stacked agreements; this is the ammo for the replay.
  - **MOMENTUM line** (new) — text-observable engagement read (leaning in / neutral / guarded), defaults to neutral (never reads enthusiasm into silence).
  - **Token cap 1200 → 1500**; downstream: `kb-signal/route.ts` summary slice 4000 → 8000 chars (new sections must not get chopped); `dig-prompt.mjs` two wording edits ("at-risk"→"objected", "THEIR EXACT WORDS"→"KEY ANCHORS"); `sales-dna.mjs` one anchor-shape paragraph appended to `buildSummarizerDnaSystemBlock` ONLY (left `buildSalesDnaBlock` byte-identical — it's the dig card's cache key).

- **summarize route freeze-guard fix.** `src/app/api/wingman/summarize/route.ts` used to 400-REJECT any `current_summary` > 10k chars. With anchors accumulating, one oversized payload would freeze the scorecard for the REST of the call (every card reads stale state, no error shown). Changed to degrade-not-brick: warn-log at 8k, reject only at an impossible 24k. The system self-heals (output is re-capped every tick). **Sebastian's call: no trimming — raise the ceiling instead so no context is ever silently lost.**

- **Eval hardened (`scripts/test-belief-ladder.mjs`).** Added STRUCTURAL INVARIANTS asserted on every fixture AND every tick of rolling fixtures: WEAKEST LINK present (the dig card's routing input — the original truncation victim), no non-belief line starting with a digit 1–7 (close-readiness parser safety), section caps (anchors ≤8, commitments ≤3), the relabel, all section headers present. New behavior traps: polite-yes vs emotional-yes ✅ bar, regression/walk-back downgrade, commitment capture + no-invention, money-as-resources, momentum default-neutral, DNA anchor-shape (number-offer + vague prospect → anchors stay vague), and an **8-tick ROLLING fixture** proving early emotional anchors survive a full call of logistics chatter (the update-in-place behavior nothing previously verified). Added a **majority-rule de-flake** runner (clean first try → pass; else best-of-3, FLAKY-marked) so sampling noise can't red the gate while real regressions still fail hard.

- **Deepgram Audio Intelligence evaluated + rejected** for the tonality gap. Sentiment/Intent/Topic/Summarize are pre-recorded only (streaming struck through in docs); their "sentiment" is linguistic-not-acoustic (reads words, Sonnet already does that better); entity detection has no hedging judgment; our Deepgram runs inside Recall (no raw param control). Logged the real path (acoustic prosody via the existing `audio_mixed_raw` tap) to `_Inbox/2026-07-20 Prosody-Tonality Research Spike.md`.

## Decisions Made and Why

| Decision | Reason |
|----------|--------|
| Nail the summarizer BEFORE resuming the voice/signal-card refinement | The summarizer is the foundation every card reads — tuning card voice on a weak scorecard is building on sand (Sebastian). |
| Add a COMMITMENTS ledger (not in the original plan) | Cole's close is assembled from stacked verbal agreements + conditional yeses; replaying the exact commitment ("earlier you said if it gets you clients, cost isn't the issue") is the most lethal objection-handle — and it lived nowhere. |
| Add a MOMENTUM line, keep it text-only + default-neutral | An elite closer reads temperature to decide pace; but a text transcript can't hear tone, so it must never invent enthusiasm from silence. Honest proxy, not a tonality claim. |
| Reject Deepgram Audio Intelligence for tonality | Streaming-unsupported for the useful features + linguistic-not-acoustic sentiment. The real fix is acoustic prosody (future spike), not Deepgram AI. |
| Freeze-guard degrades instead of rejecting; ceiling raised, no trimming | A mid-call scorecard freeze is the worst silent failure; and trimming would silently drop important context (Sebastian) — so raise the ceiling and never trim. |
| Do NOT rename "beliefs" | Not Cole IP (belief-selling is generic); users never see the word (labels are already plain English). A code rename sweep is risk for zero user benefit. |
| Hold everything local on `feat/confrontation-dial` | Zero users; Sebastian sees changes running locally. The summarizer bundles with the pinned dial + voice track for one future release. |
