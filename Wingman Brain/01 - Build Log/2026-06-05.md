## 1. Bug fixes — #35 (disposition HUD) + #36 (double-end race)

- **#35 RESOLVED + live-tested by Sebastian ✅.** The post-call "How'd it go?" card was unresponsive on the 2nd call of a session. Root cause: rep ends call 1 without dispositioning → its card leaves `outcomeCardShown=true` (30s auto-dismiss); within that window call 2 ends → `onCallEnd` runs `hideSignal()` (re-enables mouse pass-through) then `showOutcomeCard()` **early-returns**, so the stale card sits there with clicks passing THROUGH to Zoom, then auto-dismisses unsaved. Fix in `electron/hud/index.html`: (1) `showOutcomeCard` is now self-healing (always re-init + `setMouseIgnore(false)`); (2) `setLive(true)` clears a lingering card; (3) the card now uses **hover-based capture** (no longer freezes the whole screen) and is **centered** (dedicated `outcomeIn` keyframe). `wingman-reviewer` APPROVED twice.
- **#36 RESOLVED** — verified the shared `isEndingRef` guard + `finally` reset is already in the committed Phase 1 code (`handleAutoEnd`); a simultaneous manual+auto end can't double-fire. It was filed during the Phase 1 review and the fix landed in the same PR; just never closed.
- **Lesson logged:** HUD HTML changes need a full `electron:dev` restart (the file is copied into `electron-dist/` on launch — no hot reload). This bit us mid-session.

## 3. NEW feature track — Call Continuity + Prospect Memory

Triggered by Sebastian: calls drop (WiFi) and most high-ticket sales are 2–3 call closes, so memory must persist + carry across calls. New design doc: `00 - Product/Call Continuity + Prospect Memory Design.md`.

- **Two horizons:** **drop-resume** (rejoin a dropped call) = **CORE** (reliability); **cross-call deal memory** (carry context to follow-ups) = **PREMIUM** (the moat).
- **Identity backbone = Recall calendar.** Connect Google/Outlook via Recall → prospect identified by **email** (Recall fuzzy-matches the invite to the live call; nicknames/spelling-tolerant; returns null rather than guess wrong). Participant email is behind a Recall feature flag (email them to enable).
- **Prospect/Deal page** carries everything (transcripts + Belief Ladder + metadata + **next-call game plan**). Loads into every follow-up so Wingman is never blank.
- **"Today's Calls" pre-call briefing** on the dashboard home (where you left off + the play to close them) = the daily-habit / retention unlock.
- **Deal-level "Ask Wingman"** (chat about the whole prospect across all calls) = a phat **upsell**.
- **Never silently merge** prospects (wrong-merge = disaster). Privacy: this stores identified third-party PII → per-prospect deletion + privacy disclosure become mandatory (expands compliance #33). Audio/video still never stored.

## 4. Pricing — restructured into tiers (PROPOSAL)

`06 - Finance/Tier Pricing Proposal + Unit Economics.md`. Driven by the real-cost reality (Sebastian's typical user does 3–4 calls/day ≈ 80/mo — flat $149 unlimited bleeds to ~45–62% margin).

- **Free** (10 calls) → **Core $149** (live copilot + Flight Log + Sales DNA; soft-capped ~75 calls + overage) → **Pro $299** (everything + calendar / prospect memory / briefings / deal coach + unlimited). Heavy users self-select into Pro (they want the memory features anyway) → 68–77% margin on serious users.
- **Call-counting rule DECIDED:** a call counts toward the allowance only if it ran **≥ ~10 min AND the prospect actually spoke** (no-shows/instant-bails are free; objective, not dependent on the disposition button).
