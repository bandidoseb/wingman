## Decisions locked (all detailed in `Wingman Design Language.md`)

- **North star = Granola-clean.** Warm neutrals, whitespace, calm premium. Approach = **language-first**: define tokens, approve the feel, THEN rebuild. Scope = **whole product (dashboard + HUD), one language, MANY rebuilds** (never one big-bang change — protects the live pipeline; dashboard ships via Railway, HUD needs a desktop release).
- **One language, two surfaces.** Dashboard = light/warm/calm. HUD = dark/glassy (recedes over video — `Signal Card Design Science` is load-bearing, do NOT reskin it light). Unified by SF Pro type, one calm motion curve, restraint, and the "signal blue" accent `#3557C7`.
- **Sunset gradient** (red→amber→green) is a color track reserved for SCORING only (post-call belief blocks, close-readiness). Not the accent, not the status pills.
- **ONE signal-card format for all four moves** (objection/answer/dig/close): tiny type-tag + one first-person line. No headline, no separator, **no quotation marks**. Completes the 2026-06-21 two-tier drop (only the objection card ever got migrated). ⚠️ code gap logged for the HUD rebuild.
- **Plain English, no methodology jargon** in anything the rep sees live (Sebastian emphatic). Banned: "cost of waiting," "belief," "sized the pain," etc. Governs readiness reads AND generated lines. Internal AI scratchpad may still use methodology terms.
- **Close-readiness = "have I done enough discovery to pitch?"** — driven by the Belief Ladder score. NOT on the compass → trigger (kills the press→reveal payoff), NOT a floating gauge, NOT a live checklist (Playbook rule). **Final form: a minimal shrink-to-fit status chip, one color + two words, word-only:** 🔴 Not Ready → 🟠 Continue Discovery → 🟢 Almost Ready → 🟢 Ready to Pitch. Ready = just "Ready to Pitch," no script. Word-only shrinks the generation surface to nothing → directly de-risks Sebastian's #1 fear (mediocre generated lines).
- **Signal-card color customization** (net-new, first HUD theming hook): 2 card presets (dark default + white) · 4 text presets (white, blue `#7E9BFF`, green `#4ED188`, yellow `#F1D24C`) · a color-wheel picker on both. Saved per rep, applied every call. ⚠️ build must guard readability (no white-on-white).
- **Component foundation = shadcn/ui + our tokens.** shadcn = the parts (avoids vibe-coded); tokens mapped into its theme CSS variables = the Wingman "smell." Imported shadcn-based components inherit the tokens automatically → fixes the "guest components" problem. Real enforcement = discipline: one token file, no hardcoded values, every screen from the same primitives.

# 2026-07-14 — Session 2: Design Language #1 SHIPPED (HUD quick wins)

**Type:** Build session. **Shipped [PR #48](https://github.com/bandidoseb/wingman/pull/48) — squash-merged to `main` (`f151154`) → Railway deploying.** First build of the Design Language track.

**One-line:** Killed quotation marks around every spoken card line, collapsed the three directive/all-clear chips to the one single-line card format, and re-labeled the dig tags in plain English. **Ships via Railway (server-side) — no desktop release needed; reaches even already-installed apps** because the fixes are in the generation prompt + the server-side stream decoder.

## What shipped (7 files, web/server only)
1. **No quotation marks.** ROOT CAUSE was the few-shot examples in `objection-prompt.mjs` / `dig-prompt.mjs` — they were wrapped in quotes, so Sonnet imitated them. Unquoted the examples + added an explicit "no surrounding quotation marks" output rule. BELT: new pure `stripWrappingQuotes()` in `json-line-stream.ts`, applied inside `decodeLineStream` at both the streaming-partial return (leading quote consumed, monotonic-safe) and the final `"line"` return (balanced-pair strip → empty falls to `abstain`, never a blank card). Same strip on the non-stream `parseObjection` fallback. One decoder covers objection + dig.
2. **One card format.** The three directive chips (no-objection, dig-too-early, dig-take-close) now emit ONE plain line with an **empty `header`**, so the existing packaged HUD renders them via its single-line headless path (route-only change — no client edits, per plan-reviewer). Copy Sebastian-locked: *"No objection right now — keep going." · "Start the conversation." · "They're ready — go for the close."*
3. **Plain-English tags.** Dig belief tag maps the raw taxonomy id → our pillar names (`Pain → Core Problem`, …) at the DISPLAY site only; the wire value stays the taxonomy id (feeds `readBelief`/eval — must not change).

## Decision made this session
- **"Start the conversation." is a deliberate exception to the always-a-question dig doctrine.** It only fires in the pre-conversation edge (rep pressed ↓ before *anyone* spoke — zero transcript, nothing to build a question from). In-flow, dig always surfaces a real question. Sebastian rejected a scripted opener ("everyone opens differently — don't force a shitty opening sentence") in favor of a generic, non-prescriptive nudge. Chosen "Start the conversation" over "Begin discovery"/"Build rapport" (those quietly prescribe a mode).

## Gates (all green before merge)
- **plan-reviewer** hardened the plan pre-build: caught that the real root cause was the quoted few-shot examples (not just a missing fence), that the directive collapse could be route-only (smaller blast radius), and the strip edge cases (quote-then-space, balanced-pair trailing, strip-to-empty→abstain).
- **187 unit tests** pass (15 new decoder/quote tests) · web typecheck clean.
- **dig-eval:** PASS — tonality 5.00, 0 fabrication, 100% right-belief. **objection-eval:** PASS — tonality 4.90, 0 fabrication, 7/7 abstains, **0/30 outputs quoted** (proves the fence fixed it at the source).
