## Decisions locked (all detailed in `Wingman Design Language.md`)

- **North star = Granola-clean.** Warm neutrals, whitespace, calm premium. Approach = **language-first**: define tokens, approve the feel, THEN rebuild. Scope = **whole product (dashboard + HUD), one language, MANY rebuilds** (never one big-bang change — protects the live pipeline; dashboard ships via Railway, HUD needs a desktop release).
- **One language, two surfaces.** Dashboard = light/warm/calm. HUD = dark/glassy (recedes over video — `Signal Card Design Science` is load-bearing, do NOT reskin it light). Unified by SF Pro type, one calm motion curve, restraint, and the "signal blue" accent `#3557C7`.
- **Sunset gradient** (red→amber→green) is a color track reserved for SCORING only (post-call belief blocks, close-readiness). Not the accent, not the status pills.
- **ONE signal-card format for all four moves** (objection/answer/dig/close): tiny type-tag + one first-person line. No headline, no separator, **no quotation marks**. Completes the 2026-06-21 two-tier drop (only the objection card ever got migrated). ⚠️ code gap logged for the HUD rebuild.
- **Plain English, no methodology jargon** in anything the rep sees live (Sebastian emphatic). Banned: "cost of waiting," "belief," "sized the pain," etc. Governs readiness reads AND generated lines. Internal AI scratchpad may still use methodology terms.
- **Close-readiness = "have I done enough discovery to pitch?"** — driven by the Belief Ladder score. NOT on the compass → trigger (kills the press→reveal payoff), NOT a floating gauge, NOT a live checklist (Playbook rule). **Final form: a minimal shrink-to-fit status chip, one color + two words, word-only:** 🔴 Not Ready → 🟠 Continue Discovery → 🟢 Almost Ready → 🟢 Ready to Pitch. Ready = just "Ready to Pitch," no script. Word-only shrinks the generation surface to nothing → directly de-risks Sebastian's #1 fear (mediocre generated lines).
- **Signal-card color customization** (net-new, first HUD theming hook): 2 card presets (dark default + white) · 4 text presets (white, blue `#7E9BFF`, green `#4ED188`, yellow `#F1D24C`) · a color-wheel picker on both. Saved per rep, applied every call. ⚠️ build must guard readability (no white-on-white).
- **Component foundation = shadcn/ui + our tokens.** shadcn = the parts (avoids vibe-coded); tokens mapped into its theme CSS variables = the Wingman "smell." Imported shadcn-based components inherit the tokens automatically → fixes the "guest components" problem. Real enforcement = discipline: one token file, no hardcoded values, every screen from the same primitives.
