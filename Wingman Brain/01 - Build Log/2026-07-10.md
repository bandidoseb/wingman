# 2026-07-10 — #47 Deploy state machine (bulletproof + Granola-solid)

## What was built (NOT yet pushed — local branch, awaiting Sebastian's go)
Fixed **Known Issue #47** — Deploy felt flimsy and, when spammed, tore down a successfully-started call. Root cause (found via an instrumented test build, not the notes): a **concurrency race**, not just detection latency. `call:start` had no re-entrancy guard, and `initRecallAI()` returned `false` for TWO reasons — genuine failure AND "already starting/running" — so a second press ran the failure-rollback path on top of the live call, ending it in ~2s with no transcript.

### The fix — a single-owner Deploy state machine in the Electron main process
`idle → searching → starting → live → stopping`, owned by `electron/main.ts`, plus a **generation/epoch token** so a press suspended across its two awaits (arm-and-wait, then initRecallAI) bails cleanly if the world changed under it.

- **Idempotent Deploy** — mashing the button = harmless no-ops (`busy`). Kills the teardown.
- **Arm-and-wait** — press once; if the call isn't detected yet it shows "Looking for your call…" and **auto-starts the instant it's found** (30s timeout, cancellable, "still looking…" nudge at 15s). No more spamming.
- **Pushed `deploy:state`** drives the dashboard button + HUD toast (label / spinner / Cancel).
- Tray detection pre-gate removed + detection toast suppressed mid-deploy → all entry points behave identically.

## Researched + confirmed (memory: `reference_recall_detection_constraints`)
- **Detection is Space-bound by design** (Recall docs): macOS Zoom/Meet must be on the current virtual Space; **Teams is exempt**; focus doesn't matter, minimized windows can't be detected. Not a Wingman bug. Arm-and-wait + the swipe hint are the mitigation.
- **Why we can't just copy Granola:** Granola = system audio + calendar (no window detection); Fathom = server-side bot. Both lose clean per-speaker separation (prospect vs rep) — which Wingman needs. Recall's window SDK gives us that, at the cost of the Space limit.
- **Recall cost:** $0.50/hr record + $0.15/hr transcribe, **billed per second**, no per-start fee. Start/stop cycling ≈ free; a failed start = $0. The rate limiter is purely an anti-abuse guard (leaked token), not a cost-of-legit-use guard.
- **The on-screen "1440x1080" overlay is Recall's native layer, NOT our code** (our HUD only logs dims to terminal). No disable flag in docs. Likely dev-only — confirm on the packaged/notarized build.
