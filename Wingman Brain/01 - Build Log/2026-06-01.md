## What Got Built Today

**1. Deep research on state-of-the-art Claude Code workflows** (3 parallel research agents, all sourced):
- How the Anthropic CC team + Boris Cherny ship fast: plan-first → one-shot, "give the agent a check it can run" (2–3x quality), adversarial fresh-context review, hooks as deterministic gates, worktrees for parallelism. Key sources: code.claude.com/docs/en/best-practices, the Pragmatic Engineer Boris interview, claude.com/blog/code-review.
- Top-practitioner setups (worktrees, subagents, hooks, MCP) and the honest limit: parallel agents are a liability on tightly-coupled stateful code (our Electron state machine), great on independent surfaces.
- Quality-at-speed: reviewer-not-writer, commit failing tests first, hooks (PostToolUse fast checks + Stop gate), "compiles ≠ works."

**2. Built the dev harness** (merged via PR #1 — first run of the new pipeline):
- **`wingman-reviewer`** subagent (`.claude/agents/`) — the full Review Checklist, moved OUT of CLAUDE.md, runs fresh-context on every diff. Flags only correctness/security/cost bugs.
- **`plan-reviewer`** subagent — the Plan Review Loop, automated.
- **typecheck-gate** Stop hook (`.claude/hooks/`) — blocks ending a coding turn unless `tsc` (web + electron) AND `npm test` pass. Scope-aware; instant on non-code turns; detects new untracked files (a bug caught + fixed in my own first version).
- **env-guard** PreToolUse hook — deterministically blocks edits to `.env*` (enforces hard rule #1).
- **Vitest + 28 unit tests** for pure logic: keyword triggers (incl. rep-speaker exclusion), rep-profile close-rate/DQ math + JSON-parse fallbacks, poll intervals. Wired into the gate.
- **CLAUDE.md trimmed** — Review Checklist replaced with a pointer to the subagent (per Anthropic guidance that bloated CLAUDE.md gets ignored).

**3. CI + branch-protection workflow:**
- `.github/workflows/ci.yml` — typecheck (web + electron) + tests on every PR.
- `.github/workflows/security-review.yml` — Anthropic's open-source AI security review on every PR.
- CLAUDE.md Shipping section rewritten to branch → PR → review → merge (no more direct push to `main`).
- Branch protection (ruleset) active on `main`: require PR, require `checks` status, require up-to-date branches, block force pushes, restrict deletions. Approvals = 0 (solo), admin bypass left available (no self-lockout).

## Decisions Made and Why

| Decision | Reason |
|----------|--------|
| Build a dev harness before the build sprint | Make fast building *safe*: deterministic gates + fresh-context review catch the bugs a non-technical founder can't. |
| Move Review Checklist into a reviewer subagent | Anthropic: bloated CLAUDE.md gets ignored. Runs more reliably as fresh-context review on every diff. |
| Seed real tests now (not later) | `tsc` checks shape, not behavior. Tests make "it works" a runnable check — the #1 principle from the research. |
| Adopt branch → PR → review → merge | Every push currently deploys to the live product with zero gate. PRs + CI + security review protect `main`/Railway before the customer phase. |
| Tokenless remote + keychain | A PAT was exposed in the remote URL. Keychain keeps credentials out of the repo. |
