## Decisions Made and Why

| Decision | Reason |
|----------|--------|
| Distilled queries search at 0.60 (raw path stays 0.65) | Probes: honest matches 0.60–0.75, noise ≤0.54; the distilled query only exists when Groq confirmed a real objection, so it earns the lower bar |
| Prompt caching excluded from kb-signal | ~430-token system prompt < Haiku's 2,048-token cacheable minimum — physically cannot engage; warm-up + short query are the real levers |
| Nudge = fixed honest headline + AI pointer with static fallback, 3s cap | When no objection exists, the honest answer is already known — never make the rep wait long for a bonus tip, never guess |
| ←↓→ show "coming soon" pill until Phase 4 | Dead air is the bug class 3.5 exists to kill |
| Groq-down degraded mode skips the search cache | The near-static raw-buffer cache key can serve the PREVIOUS objection's technique for a new one |
| OpenRouter as middleman + per-press model bouncing — both rejected; failover-only locked | Middleman = new single point of failure + tax on every press; model bouncing = 3× prompt-tuning surface + inconsistent card voice mid-call |
| Failover mechanism (per-press vs breaker vs both) = decide by testing | Sebastian's call: play with both against real/simulated failures, pick by observed behavior |
| Groq paid tier before beta scale | Free tier ≈ 23 presses/min fleet-wide; paid ≈ $10/mo at 1,000 daily users |
