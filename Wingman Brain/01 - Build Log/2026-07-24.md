## What shipped (all local, dev-only, wingman-reviewed + typecheck-clean)

**Flight Recorder — full-call dev telemetry.** Captures EVERYTHING a live local call does → readable
per-call report Claude reads + an owner dashboard tab. Spec: `tasks/plan-flight-recorder.md` (hardened
via plan-review). DEV-ONLY gate (`NODE_ENV !== production && WINGMAN_DEVLOG=1`; renderer also
`NEXT_PUBLIC_WINGMAN_DEVLOG`; Electron `!app.isPackaged`). Never affects the live call; prod-inert.

- **Phase 0 — sink + gates:** `src/lib/wingman/devlog.ts` (per-callId WriteStream, 32KB field cap,
  rolling-20 retention, never-throws), `POST /api/wingman/devlog` route, `dev-logs/` gitignored,
  `next.config.ts` watcher-ignore for `dev-logs/`.
- **Phase 1 — server capture:** header (Sales DNA + start) in `session/route.ts`; per-card payload +
  raw line + tic-result + timing in `kb-signal/route.ts` (objection + dig branches, logged in the
  finally after controller.close — zero hot-path perturbation); summarizer in/out/usage in
  `summarize/route.ts`. Client sends `call_id`. (Exact CARD tokens deferred = Phase 1b; summarizer
  tokens already exact.)
- **Phase 2 — renderer capture:** `devlog-client.ts` (gated fire-and-forget); presses logged once at
  the true dispatch entry (`onMenuPick`), drops, and → close readiness reads.
- **Phase 3 — main capture:** `electron/measurement-log.ts` dual-writes `dev-logs/*.main.jsonl`
  (Deepgram partials + finals + presses + Recall lifecycle) — byte-identical to #41 when gated off;
  correlated to the server log via a renderer→main `devlog:link` IPC (`preload.ts` + `main.ts`).
- **Phase 4 — offline analysis:** `src/lib/wingman/flight-recorder-core.mjs` (shared merge/analysis) +
  `scripts/flight-recorder.mjs` (CLI → `dev-logs/call-<id>.report.md`). Produces the chronological
  "call film" + card adoption (heuristic) + hallucination-watch + belief trajectory + cost tally.
- **Phase 5 — Owner dashboard:** owner-gated `/owner` (`src/app/owner/page.tsx` +
  `src/components/owner/OwnerDashboard.tsx`), owner check extracted to `src/lib/owner.ts` (changelog
  repointed). Flight Recorder tab (call picker · terminal-style film · sections · "Copy everything" ·
  per-card notes) via `GET /api/wingman/devlog/report` (double-gated dev+owner, callId charset-guarded).
  Users/Revenue/Cost tabs stubbed. **Sebastian saw it: "looks weird but it'll work for now" → UI

## Bugs the recorder CAUGHT on its first live runs (both in Known Issues)
- **#53 → Close press freezes the whole compass ~40s.** handleClosePick forces a fresh summarize and
  holds the SHARED `isGeneratingRef` while awaiting it; summaries take 5–10s and rapid close presses
  trip the 30s summarize rate-limit (429) → every press dropped for ~40s. `CLOSE_SUMMARIZE_WAIT_MS=8000`
  fallback not saving us. Task brief written.

  open, repeated dig presses returned the take-close nudge instead of a question. Rep live reaction:
  "completely incorrect", "all the cards are broken". Task brief written.
