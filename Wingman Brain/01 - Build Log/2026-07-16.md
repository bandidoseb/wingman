## 2. Real listening waveform (5 files — Recall audio → pill bars)
The pill bars now react to REAL speech loudness (rep + prospect, mixed). Research first confirmed Recall's
Desktop SDK already streams `audio_mixed_raw.data` (base64 mono 16k S16LE PCM) over the channel we already
use — no extra Recall cost, no new mac permission.

- **`recall-upload-token/route.ts`** — OPT-IN: defensive `req.json()` parse (old apps send no body → no-op),
  conditionally subscribes `audio_mixed_raw.data` only when `{wantAudioLevel:true}`. Keeps every existing
  install byte-identical until the new app ships.
- **`recall.ts`** — `onAudioLevel` option; sends the opt-in flag on the token fetch; new `audio_mixed_raw.data`
  branch at the TOP of `realtimeHandler` (throttle ~25Hz → base64 decode → Int16 RMS → 0..1 clamp → emit,
  then return). **Audio NEVER stored** (Invariant #6): buffer RMS'd + discarded; one-time debug log prints
  KEYS only via `console.log` (never `logMeasurement`/bytes); returns above all disk-writing paths; doesn't
  touch `lastChunkAt`/dedup/`onChunk`.
- **`main.ts`** — wires `onAudioLevel` → `hudWindow.send('hud:audio-level', level)` with `isDestroyed()` guard.
- **`preload.ts`** — `onAudioLevel` on the hud bridge.
- **`index.html`** — `handleAudioLevel` + single rAF loop lerping bar `scaleY`, `.audio` class disables the CSS
  ambient anim (`!important`, after `.live`), ~1s fallback to ambient if audio stops, teardown in `hideHub`.

**Gates:** plan-reviewer hardened (opt-in flag, CSS-override trap, rAF lifecycle, NaN guard, PCM-to-disk audit).
wingman-reviewer = **APPROVE, no defects.** Typecheck clean (web+electron), 187 tests. **Live-tested good.**
Two live-verify items were fine: the base64 field path + PCM format (both fail safe to ambient if wrong).

## What got built (the dial — PINNED, inert by default)
- **Rep-level named dial:** `consultative < balanced < direct(default) < challenger`. Adjusts DELIVERY
  intensity only — never the diagnosis, never fire/abstain. `direct` = byte-identical to today's prompt;
  any missing/unknown value → `direct`, so the dial is **INERT until a level is set** (zero-regression proven).
- Files (all on local branch `feat/confrontation-dial`, commit `cf468da`, NOT pushed):
  `objection-prompt.mjs` + `dig-prompt.mjs` (`CONFRONTATION_MODIFIERS` + `build*SystemPrompt(level)`),
  `objection-signal.ts` / `dig-signal.ts` / `kb-signal/route.ts` (thread `confrontation` param),
  `types/index.ts` (`ConfrontationLevel` + `CardStyle`), `supabase/migrations/010_card_style.sql`
  (`card_style` jsonb col + `set_card_style_key` SECURITY DEFINER RPC — NOT run in Supabase yet),
  `scripts/confrontation-eval.mjs` (the gate).
- Gates (`node scripts/confrontation-eval.mjs`): byte-identity · judge-validation (validate the A/B ruler
  FIRST) · fire/silence stability · intensity ordering (per-fixture non-inversion + corpus ≥75% strong
  separation) · no-fabrication · length · tonality-mean floor · challenger-not-too-far. **ALL HARD GATES
  PASS**, stable across 2 full 116-card runs (dual judge Claude + gpt-4o). wingman-reviewer APPROVE
  (byte-identity verified empirically; added `service_role` GRANT to the migration). plan-reviewer hardened

- Finding: the dial is EMPHATIC on objection cards, SUBTLE on dig (correct — money/support asked gently per

## The pivot (why the dial is now pinned)
Sebastian (final tonality judge) read the 116-card batch and flagged **AI tics the AI judge scored 4.8/5 and
could not feel**: overuse of "can I ask / can I ask you something (honestly)", "come on" (esp. challenger),
forced-empathy clichés ("getting burned is real", "that feeling makes total sense"), permission-ask-then-wait
awkwardness, and one nonsensical line. His rewrites are more flowy/human ("honestly —", "I'm curious", "I
gotcha", acknowledge-then-flow-straight-into-the-question). **The dial multiplies the base voice**, so the
base voice must be nailed FIRST. His verbatim feedback + gold rewrites captured in `tasks/card-voice-spec.md`.

## Decisions (Sebastian, 2026-07-16 S2)
- **Voice before dial.** Pin the confrontationalness dial (inert, nothing lost); rework the CORE card voice
  first. Dial + a future formality dial sit ON TOP of a nailed voice.
- **No throwaway placeholder UI** — the dial UI doesn't exist yet; build the real control when we return.
- **Core-voice solution (agreed):** (1) encode Sebastian's rewrites as the FEW-SHOT examples in the base
  objection + dig prompts (model imitates examples > rules); (2) a DETERMINISTIC tic-detector hard gate in the
  eval (regex ban-list → auto-fail, since the AI judge can't feel the tics); (3) human-in-the-loop tuning loop
  (generate → Sebastian reacts → encode → repeat; multi-session craft). Bar = "Cole Gordon reads a card and
  thinks *this is legit*."
- **Held local:** dial committed to `feat/confrontation-dial`, NOT pushed (half-feature we're about to rework;
  inert; no UI). Snapshot of pre-change prompts saved to `tasks/prompt-snapshot-2026-07-16/`.
