  2. **No `.zip`** — Squirrel.Mac (electron-updater's mac engine) can ONLY apply a `.zip`, never a `.dmg`; the build made only dmgs. → added a `zip` target (kept dmg for first manual download).
  3. **Notarization off** (`notarize: false`) despite all Apple secrets existing. → `notarize: true` (Developer ID cert confirmed correct; CI now notarizes — no more Gatekeeper warning, no more `xattr`).
  4. **Private repo → 404 (the real root cause).** Live test log showed `GET bandidoseb/wingman/releases.atom → 404`: a private repo has no public release feed, so the installed app can't see updates. → publish signed/notarized installers to a **separate PUBLIC repo `bandidoseb/wingman-releases`** (source stays private); electron-updater reads there. Auth via a fine-grained PAT `WINGMAN_RELEASES_TOKEN` (Contents:write on that repo only).
  5. **Empty-repo 422** — GitHub won't attach a release to a repo with zero commits; the new public repo was created empty. → seeded a README.
  6. **No auto-relaunch** — the main-window `close` handler *hides* unless `isQuitting` is set, so `quitAndInstall()` left the process alive (user had to force-quit 2–3×). → set **`isQuitting = true` before `quitAndInstall()`**.

# Session 2 (2026-07-01) — Multi-Turn Objection Threading: design + Phase A

**What this session was:** picked up the priority-bumped multi-turn threading. Full design session with
Sebastian, hardened the plan through 2 plan-reviewer passes, built + verified **Phase A** (the intelligence
layer) + a hardening batch. Nothing committed/pushed yet — all local, awaiting review.

## The design (decided with Sebastian)
The rep handles an objection, gets card 1, and enters an **Objection Flow**: a single ↑ per beat gives the
NEXT move, never a restart, never a repeat, carrying the FULL micro-context of the exchange.
- **Decouple Mode (single-↑ gesture, owned by `main.ts`) from Thread (context we feed Sonnet).** Mode
  stays armed to a 2-min idle timer; Thread resets on abstain / new-objection / gap. Dismiss does NOT reset.
- **The Flow Ledger** (append-only from flow-open): `linesGiven[]` verbatim (never scrolls off → kills
  beat-6-repeats-beat-1) + an **anchored transcript** from the objection's opening (not the sliding 120s
  → never loses the opening) + a **frozen belief snapshot**.
- **Caching = the same shape as the append-only ledger** → doctrine + belief + history are the stable
  cached prefix; the moving "latest response" marker lives in the UNCACHED tail (a marker inside the cache
  busts the prefix each beat). Result: **beat 8 as fast as beat 1**, ~0.3¢/beat.
- **Beat doctrine is dynamic, not a script.** Combined card affordance chosen (blue "Objection Flow active"
  header + beat counter + "Press up arrow for next move"). Owner-dashboard idea captured in `_Inbox/`.

## Phase A — built + verified (offline, wired-but-single-shot)
- `objection-prompt.mjs` — threading doctrine (advance-don't-restart, don't-repeat, no-response/fragment
  abstain, gap re-evaluate, handle-before-close, circle-back) + shared cache-aware `buildObjectionUserSegments`.
- `objection-signal.ts` — `buildUserContent` (segments → content blocks + `cache_control`), optional
  `ObjectionThread` param through `generate`/`streamObjectionCard`. **Single-shot user message byte-identical.**
- `scripts/objection-threading-eval.mjs` — NEW gate: 19 fixtures across every objection type, Claude +
  optional **GPT-4o cross-check** (`JUDGE_PROVIDER=openai`), majority threshold, `advisory` known-limits
  bucket, deterministic builder↔doctrine desync guard.
- **2 plan-reviewer passes** caught real bugs before code (moving-marker-busts-cache; poller does NOT keep
  the full transcript → Phase B must build an accumulator; single-↑ IPC race → Mode in main; switch flakiness).
- **1 wingman-reviewer pass** approved the shipping code; caught the ~67% switch reliability → fixed doctrine.

## Findings (accepted)
- **Strong** on all major objection types + switches + continue-after-gap + clear-echo abstain.
- **One real, non-harmful weakness — repeat-on-circle-back** (~40-60%): rewords an angle when the prospect
  circles back to one already used. Both Claude AND GPT agree on the clearest case. Prompt-only ceiling.
  **→ Sebastian accepted it; permanent fix = the similarity retry-guard, planned into Phase B (B4).**
- **Advisory known-limits** (measured, not gated): mid-turn press detection (needs #41 partials) and
  beat-9 exhaustion (a 9-beat objection is a stall → close, don't reframe).
- **Single-shot tonality held at 5.00** — doctrine growth didn't regress it.
