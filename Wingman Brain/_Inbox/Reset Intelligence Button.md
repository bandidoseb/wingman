# Feature Idea: Reset Intelligence Button
- **Problem:** When a sales rep switches companies or products, the accumulated 'Offer Intelligence' and 'User Intelligence' data in Supabase becomes irrelevant or even harmful to new suggestions.
- **Solution:** A button to wipe the user's intelligence data clean so Wingman can start learning a new offer from scratch without legacy data interference.
- **Value:** Ensures the product stays flexible if a user's professional context changes, preventing legacy offer patterns from throwing off live signal cards.
